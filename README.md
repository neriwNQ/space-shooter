# space-shooter
Space shooter is a 2D game where you have to fight hordes of aliens in outer space. In the future there will be further development to an AAAA project.
========
First you need to install the pygame-menu 4.4.8 library using the pip install pygame-menu 4.4.8 command.
========
Control in the game using the A and D buttons (movement to the right and left).
========
Enemies fall from the top border of the screen at a random speed and with a random coordinate.
